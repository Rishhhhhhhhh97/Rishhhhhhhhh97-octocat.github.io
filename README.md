# FinBridge Loans & Partner Portal

A responsive finance web app that provides:

- All major loan categories.
- NBFC bank listings under each loan category.
- Unified login/registration interface for both:
  - Normal users
  - DSA partners
- Authentication using either:
  - Email + password
  - OTP flow (demo OTP shown on screen)

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
